# Neovim Configuration

## Philosophy

This is a minimalist Neovim setup optimized for **reading and reviewing code**, not writing it.

Most code is generated by LLMs, so this configuration focuses on:
- Fast file navigation
- Efficient code browsing
- Clear syntax highlighting
- Minimal distractions

The goal is to keep things simple and lightweight for code review workflows.

## Configuration Structure

This setup uses [lazy.nvim](https://github.com/folke/lazy.nvim) for plugin management.

```
~/.config/nvim/
├── init.lua           # Entry point
├── lua/
│   ├── options.lua    # Neovim options and settings
│   ├── keymaps.lua    # Key mappings
│   └── plugins/       # Plugin configurations (lazy.nvim)
└── lazy-lock.json     # Plugin version lock file
```

- **lazy.nvim** handles all plugin installation and loading
- **options.lua** contains editor settings (tabs, line numbers, etc.)
- **keymaps.lua** stores all custom key bindings
